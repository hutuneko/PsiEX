This Mod is an Addon based on the Psi Mod by Vazkii, born from being completely inspired (literally, 'brain-fried') by the "combining diverse elements" concept seen in moffy's TiCEX.

It features various cross-Mod compatibility elements. These include an Iron's Spellbook that can cast Psi spells, the Tinkers' Construct integration of the CAD, and extensions to Psi's core functionality.
